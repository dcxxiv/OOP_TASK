Project Overview

This project demonstrates core Object-Oriented Programming (OOP) concepts in C++ focusing on object creation, destruction, memory management, and object relationships.


Tasks Included

Task 1: LIFO Behavior on Stack

* Shows constructor and destructor execution order.
* Demonstrates Last In, First Out (LIFO) behavior of stack memory.

Task 2: Stack vs Heap

* Compares stack and heap memory.
* Uses `new` and `delete`.
* Explains memory leaks.

Task 3: Copy Constructor

* Implements default, parameterized, and copy constructors.
* Demonstrates different copy initialization methods.

Task 5: Object Composition

* Implements `Car` and `Engine` classes.
* Demonstrates constructor/destructor order in composition.

Task 8: Pointer Reassignment

* Shows how memory leaks occur.
* Demonstrates proper memory management.



💻 Language Used

C++

Objective

To understand object lifecycle, memory behavior, and safe memory management in C++.
